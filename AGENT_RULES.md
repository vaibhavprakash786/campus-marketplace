# Agent development rules
1. Work only on the stage explicitly approved by the developer.
2. Inspect existing code before editing.
3. Never regenerate the entire project unnecessarily.
4. Make small, focused changes.
5. Preserve working functionality and existing interfaces.
6. Do not add future-stage features prematurely.
7. Validate all untrusted input on the backend.
8. Enforce authorization for every protected resource.
9. Never hardcode secrets.
10. Add or update tests for relevant behavior.
11. Never claim a test passed unless it was executed.
12. Inspect the Git diff before considering a stage complete.
13. Report all changed files, test results, and unresolved issues.
14. Stop at the end of the approved stage and wait for explicit approval.
15. If a decision materially affects architecture or security, explain the trade-offs and ask before proceeding.
